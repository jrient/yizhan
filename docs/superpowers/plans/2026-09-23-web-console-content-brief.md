# 派单三:控制台页面内容优化

只改 `gateway/web/static/app.js`、`app.css`,必要时改 `gateway/web/templates/*.html`(改了要说明)。
不要改 `.py`、不要改接口、不要改 `tokens.css` / `base.css`、不要加依赖。
**保留**这两处已有实现不要动:`css()` 辅助函数(探针元素解析 token,原因见注释)、
会话柱状图的 `y: { range: … [0, max*1.15] }`(柱状图基线必须是 0)。

服务在 `http://127.0.0.1:8760`,口令 `-9dvzp7feBusyoSO`。改完刷新即可,不用重启。

## 背景:这页是给谁看的

运维自己和以后分享的同事。他们打开控制台想知道三件事:**机器人现在好不好、最近在忙什么、有没有要我管的事**。
现在的页面暴露了太多内部代号和对运维无意义的指标,关键信息反而要点进去才看得到。

## 一、卡片墙(首页)

现在一张卡上有「心跳 24 秒前」「上次上下文 393.8k」「最近告警 probe_failed(红字)」。问题:

- 心跳现在是定时打的,永远是几十秒前,说明不了任何事 → **去掉**。
- 「上次上下文 393.8k」是黑话 → **移到详情页会话页签**,卡片墙不放。
- 最近告警显示原始代号,而且那是两天前的旧事,当前明明「正常」却挂着红字 → 后端已改成只返回 24 小时内的告警,
  并带中文 `label` 和正文 `text`。**没有告警时不显示这一行**;有的话显示 `label` + 相对时间,颜色用警告色不用危险色(它不代表现在还坏着,健康点才代表现在)。

**新增**:「最后动静」—— 取 `last_msg_at`(最后一条用户消息)和 `last_reply_at`(最后一次机器人回复),
显示成「3 小时前有人提问 · 2 小时前回复」这种。这是判断机器人最近在不在干活最直接的一行。

卡片墙字段建议顺序:健康点+实例名+健康原因 / 最后动静 / 今日 消息·卡·回复 / 待处理(>0 时高亮)/ 今日用量(折算)/ 服务状态 / 24h 内告警(有才显示)。

## 二、详情页 · 概览

- 「心跳 39.5s」数字块 → 换成「最后动静」(同上)。
- 「上次上下文」保留但改名「会话上下文」,并加一行小字「越大越慢,单轮越贵」。
- 「卡状态分布」现在是英文代码块 `answered: 13` → 用 `overview.card_state_list`(已带中文 `label`),渲染成带颜色的中文徽章:已答复 / 待处理 / 处理中 / 挂起等待 / 卡死。
- 「最近告警」现在是原始代号列表 → 用 `alerts[].label` 做标题、`alerts[].text` 做正文(可能为 null,为 null 就不显示正文)、`at` 做时间。

## 三、详情页 · 卡(改动最大)

现在一行只有 编号/状态/发起人/消息数/建于/首回耗时/重派,**看不出每张卡问的是什么**,16 行必须逐个点开。

新列顺序:

| 列 | 字段 | 说明 |
|---|---|---|
| 编号 | `id` | |
| 内容 | `preview` | **最重要的一列,给最宽**。已去掉 @机器人 前缀,最长 60 字 |
| 发起人 | `sender_name` | |
| 来源 | `source` | 「群」或「私聊」,小徽章 |
| 状态 | `state_label`,颜色按 `state` | 中文。answered 绿、open 蓝、answering 黄带动画、waiting 灰、stuck 红 |
| 回复 | `n_replies` | 条数 |
| 首回耗时 | `first_reply_s` | 格式化成「1分37秒」「56秒」,null 显示「—」 |
| 时间 | `created_at` | 今天的只显示 `HH:MM`,不是今天的显示 `MM-DD HH:MM`,不要带年份 |

去掉「重派」列(几乎永远是 0);重派 >0 时在状态徽章旁加一个小标记即可。
筛选下拉的选项也用中文。

卡详情抽屉:状态显示 `card.state_label`。

## 四、详情页 · 会话

- 「新鲜度 (Fresh) 否」是黑话 → 改成「会话状态:进行中」(fresh=0)/「新会话,尚未开始」(fresh=1)。
- 「会话上下文」显示最新一轮的 `context_tokens`,带一句说明。

## 五、全局

- 所有页面不再出现英文状态码(answered / waiting / open …)和告警代号(probe_failed …)。
- 时间统一:今天 `HH:MM`,非今天 `MM-DD HH:MM`,相对时间用「N 分钟前 / N 小时前 / N 天前」。写一个公用函数。

## 交付

说明改了哪些地方;`grep -nE 'answered|waiting|probe_failed|stale_open'` 在渲染出的文案里不应再出现(代码里作为映射键可以有)。
自检硬编码颜色:`grep -nE '#[0-9a-fA-F]{3,6}\b|rgb\(' app.js app.css` 除注释外应当为零。
